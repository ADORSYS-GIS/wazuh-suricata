# wazuh-suricata Documentation

The `wazuh-suricata` project integrates the Wazuh agent with Suricata, a
high-performance network intrusion detection system (NIDS). This repository
provides scripts and tests to automate the installation, configuration, and
validation of Suricata on Linux and macOS.
